# Ultimate Exam Planner

A smart, lightweight desktop application designed to help students prepare for exams in a **centralized, organized, and productive way**.  
This project is especially useful for **self-study students** who want to track progress, manage topics, store resources, and maintain focus using a Pomodoro timer.

---

## 📌 Project Overview

**Ultimate Exam Planner** provides a unified study environment where students can:
- Manage exams and subjects
- Track topic-wise progress
- Write and save notes
- Attach study resources (PDFs, videos, links)
- Use a built-in Pomodoro timer to improve productivity

The application is built using **Python** and **Tkinter (ttkbootstrap)** with **local JSON-based storage**, making it lightweight, fast, and easy to use.

---

## 🎯 Motivation

Many students preparing for competitive or academic exams rely on multiple tools such as notebooks, planners, note apps, and timers.  
This fragmentation often leads to:
- Poor organization
- Difficulty tracking weak areas
- Reduced productivity

This project aims to solve that problem by providing a **single, integrated study platform**, especially beneficial for students who:
- Prefer self-study
- Have limited access to coaching
- Need a structured yet simple study system

---

## ✨ Key Features

- **Exam Management**
  - Create and manage multiple exams

- **Subject Management**
  - Add, delete, and organize subjects per exam

- **Topic Tracking**
  - Add topics with status: `Not Started`, `In Progress`, `Completed`
  - Update status using double-click

- **Notes Module**
  - Subject-wise note-taking
  - Notes are automatically saved and persistent

- **Resource Management**
  - Attach PDFs, videos, or external links
  - Double-click to open resources using system default player/browser

- **Pomodoro Timer**
  - 25-minute focus sessions
  - 5-minute short breaks
  - Stop/reset functionality

- **Local Data Storage**
  - All data stored safely in a JSON file
  - No internet connection required
